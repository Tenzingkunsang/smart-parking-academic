# 🅿️ Smart Parking System - Frontend

A real-time parking management interface built with React, allowing users to view availability and reserve spots dynamically.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![React](https://img.shields.io/badge/React-18.x-61DAFB)
![Status](https://img.shields.io/badge/Status-Active-success)

## ✨ Features

- **Real-time Availability:** Live updates on parking spot status (Available/Reserved/Occupied).
- **Interactive Map:** Visual grid representation of the parking lot.
- **Filtering:** Visual indicators for different vehicle types (Car, Motorcycle, EV, Disabled).
- **Reservation System:** Secure booking flow with JWT authentication.
- **Responsive Design:** Works seamlessly on desktop and mobile devices.

## 🚀 Tech Stack

- **Frontend:** React.js, React Router, Axios
- **Styling:** CSS3 (with responsive Flexbox/Grid layouts), Lucide Icons
- **State Management:** React Hooks (useState, useEffect)
- **Notifications:** React Hot Toast
- **Animations:** Framer Motion
